CYBERSE PIECE DATABASE

룰 / 기물

기본 규칙
보드는 각 변이 12칸인 정육각형이다. 인접은 직접 맞닿은 6칸이다. 아군이 인접하여 끊어지지 않고 이어진 집합을 연결(네트워크)이라 한다. 초기 배치 영역은 12칸 + 13칸 = 25칸이며, 선택 기물의 총점은 75점 이하이다.

이동
폰: 전방 부채꼴 3방향 / 최대 1칸. 룩: 전후 직선 2방향 / 최대 N칸. 비숍: 양옆 측면 및 대각 4방향 / 최대 N칸. 나이트: 인접 6칸을 제외한 지정 반경 N칸에 장애물을 무시하고 도약. 퀸: 전방위 6방향 / 최대 N칸.
